# Steam.com Frontend - Complete Project Structure

## 🎮 **Project Overview**
A complete, multi-page Steam gaming platform frontend with authentic design, interactive features, and responsive layouts.

## 📁 **File Structure**

### **Main Pages**
```
├── index.html              # Homepage - Steam landing page
├── store.html              # Store page - Game browsing and purchasing
├── community.html          # Community page - Forums, groups, social
├── about.html             # About page - Company information and careers
└── support.html           # Support page - Help articles and contact
```

### **Styling Files**
```
├── styles.css              # Main CSS - Global styles and navigation
├── store-styles.css        # Store-specific styling
├── community-styles.css    # Community-specific styling
├── about-styles.css        # About page styling
└── support-styles.css      # Support page styling
```

### **JavaScript Functionality**
```
├── script.js               # Main JavaScript - Global functionality
├── store.js                # Store page interactions
├── community.js            # Community page features
├── about.js                # About page animations
└── support.js              # Support page functionality
```

### **Documentation**
```
├── README.md               # Project overview and setup
└── PROJECT_STRUCTURE.md    # This file - Complete structure
```

## 🚀 **Features by Page**

### **🏠 Homepage (index.html)**
- **Hero Section**: Steam branding and call-to-action
- **Featured Games**: Highlighted game showcases
- **Special Offers**: Countdown timer and deals
- **Categories**: Game genre navigation
- **News & Updates**: Latest Steam announcements

### **🛒 Store Page (store.html)**
- **Game Grid**: Responsive game listings with filters
- **Advanced Filters**: Category, price, features, release date
- **Sorting Options**: Price, rating, newest, relevance
- **View Toggle**: Grid and list view options
- **Game Details**: Modal popups with game information
- **Pagination**: Page navigation for large catalogs

### **👥 Community Page (community.html)**
- **Discussion Forums**: Community discussions and topics
- **Groups System**: Gaming groups and communities
- **Workshop**: User-created content browsing
- **Market**: Item trading and marketplace
- **Broadcasts**: Live streaming features
- **Guides**: User-created game guides
- **Screenshots**: Community image sharing

### **ℹ️ About Page (about.html)**
- **Company Overview**: Steam/Valve company information
- **Interactive Timeline**: Company history with animations
- **Core Values**: Company principles and mission
- **Technology Stack**: Platform and infrastructure details
- **Team Section**: Key personnel and roles
- **Careers**: Job opportunities and application forms

### **🆘 Support Page (support.html)**
- **Smart Search**: Intelligent search with suggestions
- **Help Categories**: Organized support topics
- **FAQ System**: Expandable question/answer format
- **Quick Help**: Step-by-step troubleshooting
- **Contact Options**: Multiple support channels
- **Resource Library**: Documentation and guides
